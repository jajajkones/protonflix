HTML to JSX Converter

What this does

  • Converts self-closing tags: <img> → <img />
  • Replaces class → className, for → htmlFor
  • Converts inline styles to style objects: style="color: red" → style={{color: 'red'}}
  • CamelCases HTML attributes: tabindex → tabIndex, onclick → onClick
  • Converts event handlers: onclick → onClick
  • Handles data-* and aria-* attributes (preserved as-is)
