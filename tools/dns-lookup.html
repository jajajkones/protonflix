How DNS Works

DNS (Domain Name System) translates domain names into IP addresses. This tool queries public DNS-over-HTTPS APIs to resolve various record types. Results include TTL (Time To Live) values indicating cache duration. DNS propagation can take up to 48 hours after changes.
