Barcode Types

  • Code 128: High-density alphanumeric. Supports ASCII 0-127. Most versatile. C128
  • Code 39: Alphanumeric (A-Z, 0-9, -.$/+%*SPACE). Self-checking. C39
  • EAN-13: 13-digit product code (retail). Last digit is checksum. EAN
  • UPC-A: 12-digit product code (US retail). Last digit is checksum. UPC
  • ITF-14: 14-digit shipping code. Even number of digits required. ITF
